# 🏕 Base Screen (MVP)

## 📌 Назначение

База — это навигационный экран (хаб), из которого игрок переходит в основные разделы игры.

* без сложной логики
* без NPC
* без анимаций
* минимум текста
* быстрый переход в действия

---

## 🧱 Общий принцип

* экран = набор кликабельных объектов (иконки/картинки)
* hover → короткий tooltip (1 слово)
* click → переход на отдельный экран
* вся логика находится внутри целевых экранов

---

## 🖱 Поведение

* наведение:

  * подсветка объекта
  * tooltip (например: "Магазин")

* клик:

  * переход по route
  * без модалок и промежуточных состояний

---

## 📍 Разделы (MVP)

### 1. Карта

* route: `/map`
* описание: выбор локации для ловли
* особенности:

  * проверка уровня
  * доступ/блокировка локаций

---

### 2. Снасти (включая апгрейды)

* route: `/gear`
* описание:

  * выбор удочки
  * леска
  * крючок
  * наживка
* апгрейды:

  * улучшение характеристик
  * бонусы

---

### 3. Улов (садок)

* route: `/catch`
* описание:

  * список пойманной рыбы
  * просмотр характеристик
  * быстрая продажа

---

### 4. Магазин

* route: `/shop`
* описание:

  * покупка снастей
  * покупка наживки
  * расходники

---

### 5. Квесты / Турниры

* route: `/quests`
* описание:

  * активные задания
  * цели
  * награды
  * события

---

### 6. Аккаунт / Настройки

* route: `/account`
* описание:

  * профиль
  * настройки

---

# 🎯 Что выяснили (важное)

## ❗ Проблема ассетов

Сгенерированные изображения:

- имеют **вшитый фон**
- шахматка = НЕ прозрачность
- не подходят для нормальной сцены

---

## ✅ Принятое решение

Ассеты должны быть:

- PNG
- прозрачный фон
- без:
  - воды
  - земли
  - теней-пятен
  - градиентов
